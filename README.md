## What is this
***NoShare*** - multifunctional site that include messenger and file sharing.
It is created for convenient sharing files and text between your devices.
***NoShare*** let you sharing and downloading files at maximum speed without unnecessarry registration.
> **It suits you** in case you use old device, often switch distributions and you're lazy to register in any messegers or you need to send big files to another device.
